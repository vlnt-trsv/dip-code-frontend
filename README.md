# GoRest Explorer

React-приложение для просмотра пользователей и постов через [GoRest API](https://gorest.co.in/).

## Стек

- **React 18** + **TypeScript**
- **Vite** - сборка
- **React Router v6** - роутинг
- **TanStack Query** - запросы и кэширование
- **Zustand** - глобальное состояние
- **Consta UIKit** - UI компоненты
- **Axios** - HTTP клиент

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev
```

Приложение откроется на http://localhost:5173

## Получение токена

1. Зарегистрируйтесь на https://gorest.co.in/
2. Перейдите в раздел **API Tokens**
3. Скопируйте токен и вставьте на главной странице приложения

## Сборка для продакшена

```bash
npm run build
npm run preview   # локальный просмотр сборки
```

## Структура проекта

```
src/
├── app/            # Инициализация: роутер, провайдеры
├── pages/          # Страницы по роутам
├── widgets/        # Крупные UI блоки (таблицы, пагинация)
├── features/       # Бизнес-логика (авторизация, режим)
├── entities/       # Сущности (user, post) - типы, API, UI
└── shared/         # Утилиты, константы, хуки
```
